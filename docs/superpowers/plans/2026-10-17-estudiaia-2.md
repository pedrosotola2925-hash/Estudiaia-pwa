# EstudiaIA 2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Entregar un instalador Windows de EstudiaIA 2 con voz mexicana Dalia, las funciones originales corregidas y una prueba final del ejecutable con el usuario.

**Architecture:** Electron mantiene la interfaz local y delega proveedores, claves y voz a un proceso principal aislado. Núcleo compartido UMD para validación/estado, módulos de interfaz separados y un helper de voz empaquetado, sin dependencia del Python de Hermes en destino. Un instalador NSIS y datos propios impiden sobrescribir la aplicación anterior.

**Tech Stack:** JavaScript sin framework, Node test runner, Electron 44.9.0, electron-builder 26.15.3, Playwright 1.64.1; Python 3.11 en entorno de build aislado, edge-tts 7.3.1 y PyInstaller para el helper. Fijar las dependencias Python transitivas y la versión compatible de PyInstaller en el lock de la tarea 3 después de consultar sus metadatos oficiales; no modificar el entorno Python de Hermes.

**Spec:** `docs/superpowers/specs/2026-10-17-estudiaia-2-design.md` (aprobada por el usuario).

## Global Constraints

- Nombre mostrado: **EstudiaIA 2**. Identificador: `cl.estudiaia.desktop.v2`. Versión inicial: `2.0.0`.
- Archivo de entrega: `EstudiaIA-2.0.0-Setup.exe`.
- Datos nuevos: `%APPDATA%/EstudiaIA2`, separados de la aplicación anterior.
- Instalación nueva bajo `%LOCALAPPDATA%/Programs/EstudiaIA 2`; no reutilizar el directorio antiguo.
- Predeterminada: **Dalia — Español (México)** (`es-MX-DaliaNeural`), ritmo `-5%`, tono `+0Hz` y volumen inicial de síntesis `-10%`.
- Las voces neuronales requieren internet; Gemini y YouTube seguirán siendo servicios online.
- Modelo inicial: `gemini-3.5-flash-lite`, configurable y comprobable con la clave del usuario.
- Fotos/PDF: JPEG, PNG, WebP y PDF, hasta **4 MiB por archivo**.
- Prácticas: exactamente cinco preguntas, cuatro opciones, índice correcto entero entre 0 y 3.
- Lecciones: de cuatro a seis tarjetas y una pregunta final A/B.
- Pomodoro: 25 minutos de estudio, 5 de descanso corto y 15 de descanso largo después de cuatro bloques; la siguiente fase requiere inicio explícito.
- Historial visible: últimas 20 prácticas; contador total independiente. Caché de audio: 50 archivos y 100 MB como máximos.
- `nodeIntegration: false`, `contextIsolation: true`, `sandbox: true`, `webSecurity: true`.
- No claves en el bundle, renderer, `localStorage`, trazas o comandos. El usuario las introduce en Ajustes; no se extraen de otra instalación o de Hermes.
- No modificar Claude Code, la instalación anterior de EstudiaIA ni el entorno/configuración de Hermes.
- Sin modelos locales, backend externo, migración automática ni promesas de gratuidad ilimitada, tamaño o firma digital.
- Conservar el diseño original; corregir accesibilidad y desbordamientos sin rediseño completo.
- Fixtures solo en tests, nunca respuestas simuladas presentadas como reales. Un bloqueo de API se registra como pendiente, no como prueba aprobada.
- La aceptación final incluye el ejecutable instalado y la prueba con el usuario.
- Trabajar en un worktree de implementación, no en la rama de documentación. Commits locales con identidad explícita `Hermes Agent <hermes-agent@localhost>` si no existe identidad configurada; no cambiar configuración global de Git.

## Review Focus

1. Respuesta tardía después de cerrar, cambiar de curso o cancelar: no debe reaparecer ni contaminar el curso nuevo (tareas 3, 5 y 7).
2. Escritura fallida/caché llena/historial corrupto: no perder el último estado válido, duplicar resultados o afirmar que se guardó lo que no se guardó (tareas 1 y 6).
3. Contenido hostil del modelo o iframe: no ejecutar HTML, invocar IPC privilegiado ni abrir destinos arbitrarios (tareas 2, 4, 5 y 7).
4. Suspensión del equipo, navegación repetida y doble pulsación: temporizador y contadores avanzan una sola vez (tareas 1, 6 y 8).
5. Equipo sin Python/Node externo o proveedor caído: el instalador contiene el helper y la app comunica el fallo sin bloquear la interfaz (tareas 3 y 9).

## Mapa de archivos y convenciones

- `src/shared/core.js`: funciones puras de validación, preguntas y caché. UMD: exporta `module.exports` en Node y `window.EstudiaCore` en navegador.
- `src/shared/store.js`: estado versionado y transacciones sobre un adaptador de almacenamiento. UMD: `EstudiaStore`.
- `src/shared/pomodoro.js`: reloj puro con tiempo inyectable. UMD: `EstudiaPomodoro`.
- `src/main.cjs`, `src/preload.cjs`: arranque Electron y puente fijo `window.desktop`.
- `src/services/security.cjs`, `settings.cjs`, `providers.cjs`, `voice.cjs`: permisos/IPC, configuración, Google y proceso de voz respectivamente.
- `src/voice/worker.py`: helper de voz; lee JSON por stdin, escribe únicamente audio en la ruta de caché proporcionada por main y devuelve un resultado JSON sin textos privados.
- `src/ui/index.html`, `styles.css`: aspecto y estructura basados en lo enviado; scripts locales `defer` en orden explícito.
- `src/ui/bootstrap.js`, `dom.js`, `router.js`, `settings.js`, `voice-player.js`: contexto de app, render seguro, navegación, ajustes y reproducción.
- `src/ui/tutor.js`, `materias.js`, `practicas.js`, `progreso.js`, `videos.js`, `estudiar.js`: funcionalidades de cada vista, registradas dentro de IIFEs bajo `window.Estudia.features`.
- `tests/unit/*.test.cjs`, `tests/ui/*.spec.cjs`, `tests/fixtures/`: pruebas Node, Electron y datos explícitamente ficticios.
- `scripts/`, `build/`, `requirements-voice.lock.txt`, `THIRD_PARTY_NOTICES.md`: verificación, empaquetado y dependencias/licencias.

### Contratos de datos compartidos

Estos objetos JSON son los contratos para todas las tareas; no exponer genéricamente Electron, `ipcRenderer`, filesystem ni métodos dinámicos.

- `SettingsSummary = {hasGeminiKey:boolean, hasYoutubeKey:boolean, model:string, voice:string, rate:number}`. `rate=-5` representa `-5%`.
- `Question = {p:string, o:[string,string,string,string], c:number, e:string}`.
- `MiniQuestion = {enunciado:string, opciones:[{letra:'A',texto:string},{letra:'B',texto:string}], correcta:'A'|'B'}`.
- `Lesson = {titulo:string, slides:Array<{emoji:string,titulo:string,texto:string}>, final:{pregunta:string,a:string,b:string,correcta:'A'|'B'}}`.
- `Video = {id:string,title:string,thumbnail:string}`. `id` debe cumplir `/^[A-Za-z0-9_-]{11}$/`.
- `AIRequest = {id:string, kind:'tutor'|'units'|'practice'|'lesson'|'plan'|'notes', course:string, subjectId?:string, subjectName?:string, unit?:string, question?:string, context?:string, examDate?:string, today?:string, file?:{name:string,mime:string,base64:string}}`.
- `AIResponse = {text:string}`. Errores públicos: `{code:string,message:string}` sin respuestas HTTP sin depurar ni claves.
- `AppState = {version:2,course:string,progress:Record<course,{subjects:Record<subjectId,{correct:number,total:number}>,practiceCount:number,history:Array<{id:string,at:string,subjectId:string,subjectName:string,correct:number,total:number}>,answeredIds:string[]}>,notes:Array<{id:string,at:string,technique:string,text:string}>,cache:Record<string,{text:string,at:string}>}`.
- `PracticeResult = {id:string,course:string,subjectId:string,subjectName:string,correct:number,total:5,at:string}`; `Note = {id:string,at:string,technique:string,text:string}`.
- Estado inicial: curso `7º básico`, progreso/notas/caché vacíos. Cursos y materias son exactamente los del código recibido.
- `window.Estudia` contiene `{features,store,settings,router,request,voice,ui}`; se crea antes de registrar módulos. Las funciones de vista se llaman al entrar, no durante el registro.
